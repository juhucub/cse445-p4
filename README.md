# CSE445 Project 4 - XML Validation and XML to JSON Conversion

This repository contains a C# console application for an ASU CSE445 assignment focused on XML schema validation and XML-to-JSON transformation.

## What This Project Does

The program performs two main tasks:

- Validates hotel XML files against a provided XSD schema
- Converts valid hotel XML data into JSON format

## Files

- `submission.cs` — main C# program containing validation and XML-to-JSON logic
- `Hotels.xml` — valid hotel XML input
- `HotelsErrors.xml` — invalid hotel XML input for schema validation testing
- `Hotels.xsd` — XML Schema Definition used to validate hotel data
- `bin/`, `obj/` — build output directories generated by the C# project

## Features

### 1. XML Validation
The program validates XML files against `Hotels.xsd`.

It checks:
- required structure
- required attributes
- valid element ordering
- schema compliance

The program tests both:
- `Hotels.xml` as a valid example
- `HotelsErrors.xml` as an invalid example

### 2. XML to JSON Conversion
The program reads hotel data from `Hotels.xml` and converts it into formatted JSON.

The resulting JSON includes:
- hotel name
- phone numbers
- address
- hotel ID
- rating

## XML Schema Overview

The schema defines a `Hotels` root element containing one or more `Hotel` entries.

Each `Hotel` includes:
- `Name`
- one or more `Phone` elements
- `Address`
- required `Id` attribute
- optional `Rating` attribute

## Tech Stack

- C#
- .NET Console Application
- XML / XSD validation APIs
- Newtonsoft.Json

## How to Run

1. Open the project in Visual Studio or your preferred C# IDE
2. Build the project
3. Run the application

The program will:
- validate the XML files
- print validation results
- convert the valid XML file to JSON
- print the JSON output

## Example Output

The program reports whether each XML file is valid against the schema and then prints the JSON generated from the valid hotel XML data.

## Purpose

This project demonstrates:
- XML schema validation in C#
- parsing structured XML data
- transforming XML into JSON
- working with hierarchical data formats in .NET
